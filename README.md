# Equity-risk-engine

Risk modelling on Indian equity market 


Did basic rolling predictions using capm and fama french models 
Monitored portfolio risk (volatility) across time, calculated VaR, shaarpe ratio, 
Used GARCH to model volatililty across time 
Performed regime detection using basic methods (historical data percentile splits)
Used optimization to get weights for max sharpe and min volatility portfolios
Got HHI values to assess concentration risk
Performed extreme tail-risk modelling by fitting Generalized Pareto Distribution (GPD) to tail data
